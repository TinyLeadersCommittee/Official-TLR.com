# Official-TLR.com

The official website for **Tiny Leaders: Reborn** — a fan-created, competitive 1v1 Magic: The Gathering format built on 50-card singleton decks and a hard 3-mana-value cap.

## What Is Tiny Leaders: Reborn?

Tiny Leaders: Reborn (TLR) is a player-driven Magic: The Gathering variant format that evolved from the original Tiny Leaders format created by Charlotte Tackaberry, Steven Hamonic, and Matthew Turnbull in 2013. The Reborn iteration was founded in 2018 by a group of French players — Clément Sillière, Arnaud Chalendard, and Olivier Manin — in response to stagnation in the original format's meta and a lack of active governance.

TLR emphasizes competitive 1v1 play, tight deckbuilding constraints, active banlist management, and a community-first approach to format health.

### Format at a Glance

| Rule | Detail |
|---|---|
| **Format** | 1v1 Singleton |
| **Deck Size** | 50 cards (including commander) |
| **Mana Value Cap** | Every card must be MV 3 or less |
| **Commander** | A legendary creature or planeswalker |
| **Starting Life** | 20 |
| **Sideboard** | Up to 10 cards |
| **Color Identity** | Must match commander's color identity |
| **Commander Tax** | {2} for each prior cast from command zone |

#### The Rule of 3
For split cards, Adventures, and MDFCs, **every** face or mode must independently meet the MV 3 limit — not just the face you intend to cast.

## Site Structure

The site is a multi-page resource hub for the TLR community, organized into the following sections:

### Format Library
| Page | Description |
|---|---|
| `/rules/overview` | Core rules, key mechanics, and the Rule of 3 explained |
| `/banlist` | Current banned cards and watchlist |
| `/rules/supplements` | Official rules documents, FAQ, and philosophy deep-dives |
| `/design` | Design philosophy behind format decisions |

### The Gathering (Community)
| Page | Description |
|---|---|
| `/community` | Discord community hub and overview |
| `/community/little-league` | The open online year-long competitive league |
| `/community/paper-play` | Paper Play Network — find in-person events |
| `/community/play-options` | All ways to play (Cockatrice, paper, etc.) |
| `/community/resources` | Player toolkit — Cockatrice guides, Moxfield, Manabox, Challonge |

### Foundations
| Page | Description |
|---|---|
| `/about` | Full history and origins of the format from TL:O through TLR |
| `/about/committee` | Meet the current Committee members and their roles |
| `/feed` | Latest announcements, articles, and format updates |

### In Development
| Page | Description |
|---|---|
| `/construction` | Play and Master sections — currently under construction |
